色域转换

输入 RGB 三原色的 x、y 色坐标，计算 CIE 1931 xy 与 CIE 1976 u'v' 马蹄图，并输出标准色域覆盖率和面积比。

覆盖率 = 输入色域与标准色域的重叠面积 / 标准色域面积；面积比 = 输入色域面积 / 标准色域面积。计算方式按桌面“画质计算表格/色域计算.xlsx”和 ColorAC 覆盖面积示例实现。

CIE 1931 xy 马蹄图

CIE 1976 u'v' 马蹄图

由 CIE 1931 x,y 转换为 u' = 4x / (-2x + 12y + 3)，v' = 9y / (-2x + 12y + 3)
