海信四色 B/C 波长调用逻辑

基于桌面《海信85USX客观数据.csv》的 RGB 样本与客观光谱峰值，反推出四色背光中 R、G、B、C 四个波长的调用逻辑和应用场景。

Hisense 85USX R=643nm G=524nm B=454nm C=464nm G 临界约 100
数据说明：CSV 未提供电流、PWM、时序或光谱面积，因此当前只能推导波长调用规则与场景逻辑，不能推导 B/C 电流占比。
R 波长 643nm 红色主峰，用于红色及含红色相判断的基础波长。
G 波长 524nm 绿色主峰，用于绿色、黄绿和偏青触发判断的基础波长。
B 波长 454nm 短波蓝光，纯蓝、深蓝、偏紫、偏红蓝混合场景使用。
C 波长 464nm 长波青蓝，白灰、青绿、儿童模式与鲜艳模式偏青场景使用。
关键阈值 G≥100 鲜艳模式偏青方向，实验数据表现为 G>R 且 G≥100 时触发 C。

推导过程

  1. 先按光谱峰值分类：454/455/457nm 归为 B 或 B 主导短波，463/464nm 归为 C 或 C 主导长波。
  2. 再看模式门限：结论区记录 C 仅在鲜艳/儿童模式打开，儿童模式默认全开 C，其它模式默认使用 B。
  3. 在鲜艳模式内分 RGB 条件：R=G=B 且不为 0 时，各灰阶白都落到 464nm。
  4. Green-Blue 色相扫描显示，R=0、B=255 时，G 从 60/80/90 到 100 后由 455/457nm 转为 464nm，因此可把 G≈100 作为偏青 C 触发临界点。
  5. 三色边缘验证显示 R>G 的偏紫样本走 454nm，G>R 且 G 高的偏青/黄绿样本走 464nm。
  6. R=0、G=255、B=100/128 在客观图测中出现双峰波，暂归为 B+C 混合候选；主观画面未复现，不能作为量产规则定论。

应用判定规则

儿童模式直接使用 C，默认全开 464nm。
非鲜艳/非儿童默认使用 B，按 454nm 处理。
鲜艳模式白/灰R=G=B 且不为 0，使用 C。
鲜艳模式偏青绿G>R 且 G≥100，使用 C。
鲜艳模式偏红紫色相有 R 且 R>G，使用 B。
纯蓝/深蓝使用 B；低亮蓝光样本 0/0/128 为 454nm。
B+C 候选R=0、G=255、B=100/128 出现双峰，需补测确认。

实验矩阵与结果

实验模块 样本条件 观测波长 推导结论
纯色基准 红、绿、蓝、青 643 / 524 / 454 / 464nm 确认四色背光中蓝侧有 454nm B 与 464nm C 两个可调用峰。
Green-Blue Hue Sweep R=0、B=255；G=60/80/90 → G=100/110/120/128/255 455/457nm → 464nm 偏青方向的临界点约在 G=100；G>R 且 G≥100 时转入 C。
纯蓝向纯白过渡 R=G=32/64/128/192/224，B=255；以及 255/255/255 454nm；白场 464nm 去饱和蓝不必然触发 C，只有完整白场转 C。
灰阶白验证 64/64/64、128/128/128、192/192/192、255/255/255 均为 464nm C 不只用于高亮白场，各灰阶白/灰都使用 C。
三色混合边缘 255/64/255；64/255/255；128/255/255 454nm；464nm；464nm R>G 的偏紫样本用 B，G>R 的偏青/黄绿样本用 C。
双峰候选 R=0、G=255、B=100/128 客观图测出现双峰 可能存在 B+C 同开或过渡混光，但主观画面未测到双峰，需二次验证。

应用场景归纳

C：儿童/护眼白灰 儿童模式默认 C；白、灰和大面积低饱和画面使用 464nm，可能是为了降低短波蓝占比。
C：鲜艳模式偏青绿 青、黄绿、绿色占优的样本使用 C，规则可简化为 G>R 且 G≥100。
B：蓝/紫/红蓝混合 纯蓝、深蓝、偏紫，以及 R>G 的红蓝混合样本使用 454nm。
B+C：低饱和绿蓝过渡 R=0、G=255、B=100/128 需要补测谱图、模式和主观内容，当前只作为候选场景。

实验结论

海信 85USX 四色系统里，B 与 C 不是简单按蓝色亮度线性配比，而是受模式和色相共同控制。可落地的工程规则是：普通场景走 B；儿童、白灰和鲜艳模式偏青绿走 C；偏红紫和纯蓝走 B；双峰样本暂列为混光验证项。

当前 CSV 没有电流、PWM、时序或光谱面积数据，因此只能给出波长调用比例和场景规则，不能得出 B/C 电流占比。
